## `lib/main_mode/max30102_K2/fixed30/k2_core_fixed30.dart` — `computeBuffer()` 的 classify 基準

**為什麼換**：固定模式的原則是「所有計算都用這 30 秒」，但 classify 原本沿用即時版的
局部 ±4 拍中位數。清單兩端只有 5 筆可比，3 顆壞拍就能把局部中位數拉過去、讓壞拍漏網成乾淨。

**換成**：整段 RR 中位數 ±20%（`Max30102HrvCalculator.clean(..., wholeSeries: true)`）。
74 份快照對照：65 份不變，9 份乾淨拍數有變（多半是少掉被誤收的壞拍），confidence 全部不變。

```dart
final cleanPts = Max30102HrvCalculator.clean(
  beats.samples,
  includeRecovered: true,
  apply: config.cleanEnabled,
  wholeSeries: true,
);
final hv = Max30102HrvCalculator.hrvFrom(cleanPts);
```

**舊寫法**：

```dart
final cleanPts = beats.rrCleanPts();
final hv = beats.hrvStats();
```

## `lib/main_mode/max30102_K2/ui/k2_serial_adapter.dart` — `saveSnapshot()` 的空波形檢查

**為什麼換**：提早結束（≥ 28 秒手指離開）時，即時核心在同一批資料歸零、`waveIr` 被清空，
固定版的結果還在卻存不了快照（畫面跳「快照存檔失敗」）。

**換成**：有凍結的固定版資料（`fixedBuf`）時照樣存。

```dart
if ((fixed?.ir ?? waveIr).isEmpty && fixedBuf == null) {
```

**舊寫法**：

```dart
if ((fixed?.ir ?? waveIr).isEmpty) {
```

## `lib/main_mode/max30102_K2/ui/k2_serial_adapter.dart` — `_onPacket()` 手指離開時清畫面

**為什麼換**：正常結束時 done 後停輪詢、收不到手指離開，畫面留著；提早結束的原因就是手指離開，
同一批 `didReset` 把畫面清掉、`latest` 被 noFinger 蓋掉（谷標與 RR 數字消失）。兩種結束看到的不一樣。

**換成**：固定核心在這一批提早結束（`fxEarlyDone`）時，不清畫面、不覆蓋 `latest`。

```dart
if (r.didReset) {
  if (!fxEarlyDone) _clearLocal();
  ...
}
...
if (!fxEarlyDone) latest = c;
```

**舊寫法**：

```dart
if (r.didReset) {
  _clearLocal();
  ...
}
...
latest = c;
```

## `lib/main_mode/max30102_K2/ui/k2_page.dart` — 「隱藏空轉段」只在定長模式

**為什麼換**：原本以為滾動模式的開頭段會自己滑出畫面。但固定 30 秒量測全程約 33 秒、視窗 30 秒，
開頭段幾乎整場都在，空轉期那根大波把縱軸撐大、脈搏被壓成直線。

**換成**：滾動模式畫面上接著開頭段（`headInRolling`）時，開關也出現、裁切也生效。

```dart
final dropHead = (_hideDead && preLen > 0) ? ... : 0;
...
if ((_fixedMode && fx != null && !fx.preMissing) ||
    (!_fixedMode && headInRolling))
```

**舊寫法**：

```dart
final dropHead = (_hideDead && fx != null && preLen > 0) ? ... : 0;
...
if (_fixedMode && fx != null && !fx.preMissing)
```
