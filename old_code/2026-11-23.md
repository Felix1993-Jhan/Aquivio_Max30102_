# 2026-11-23

## `lib/main_mode/max30102_K2/ui/k2_serial_adapter.dart` — `startMeasurement()`

**為什麼換**：先開始輪詢再送 init 的話，第一輪探測會連續送 `QUERY 0x31`、`QUERY 0x30`，
INIT 緊接著擠進去 —— 實測燈沒亮（同一個 INIT 封包在輪詢穩定後單獨送就會亮）。
server 一直是「init 等到回覆才開始輪詢」，沒有這個問題，所以改成同一個順序；
歸零也一起移到 init 成功之後，與 server 收到 init 成功才清結果一致。

**換成**：送 init → 等 MCU 回覆（byte[4] = RE-INIT、byte[5] = 1，最多 1 秒）→ 成功才 `reset()` + `start()`；
失敗或沒回應就寫日誌、不開始量測。

```dart
Future<void> startMeasurement() async {
  if (_roundRunning || _initWait != null) return;
  manager.onRawBytes = _parser.feed;
  final wait = _initWait = Completer<bool>();
  sendInit();
  notifyListeners();
  final ok = await wait.future
      .then<bool?>((v) => v)
      .timeout(const Duration(seconds: 1), onTimeout: () => null);
  _initWait = null;
  if (ok != true) { /* 寫日誌、卸載接收、不開始 */ return; }
  _log(tr('k2_log_init_ok'));
  reset();
  start();
}
```

**舊寫法**（0.0.1-fixed30s，c018f3d）：

```dart
void startMeasurement() {
  reset();
  start();
  sendInit();
}
```
