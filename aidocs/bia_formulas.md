## 🟢 快速版：實務上只需要這 5 條

只想快點做出東西的話，看完這張表就夠了。後面是完整參考，需要時再查。

| # | 名稱 | 公式 | 單位 | 說明 |
|---|------|------|------|------|
| 1 | **相位角** ⭐ | `φ = arctan(Xc / R) × 180 / π` | 度 | **最重要**。不需身高體重年齡性別、不需迴歸公式、不受電極配置影響。第一版建議主打這個 |
| 2 | **阻抗指數** | `II = H² / R` | cm²/Ω | 所有體組成公式的核心自變數 |
| 3 | **去脂體重 FFM** | `FFM = −4.104 + 0.518×(H²/R) + 0.231×W + 0.130×Xc + 4.229×sex` | kg | Kyle 2001，最常用 |
| 4 | **體脂率 BF%** | `FM = W − FFM`　→　`BF% = FM / W × 100` | kg → % | 脂肪是「減出來的餘數」 |
| 5 | **骨骼肌量 SMM** | `SMM = 0.401×(H²/R) + 3.825×sex − 0.071×age + 5.102` | kg | Janssen 2000 |

> ⚠️ 第 3~5 條是「手↔腳」配置推導的。**本專案是手把式（手↔手），直接套會有系統性偏差** —— 見第六部分。

## 第一部分：電學層（量測 → 阻抗）

| # | 名稱 | 公式 | 說明 |
|---|------|------|------|
| 1.1 | 複數阻抗 | `Z = R + j·Xc` | 基本定義 |
| 1.2 | 阻抗幅值 | `\|Z\| = √(R² + Xc²)` | |
| 1.3 | 相位角 | `φ = arctan(Xc / R) × 180/π` | 單位：度 |
| 1.4 | 從幅值相位反推 | `R = \|Z\|·cos(φ)`　`Xc = \|Z\|·sin(φ)` | |
| 1.5 | 電容阻抗 | `Xc = 1 / (ω·C) = 1 / (2π·f·C)` | 細胞膜的阻抗 |
| 1.6 | IQ 解調（實部） | `Real = (2/N) · Σ v(t)·cos(ωt)` | DFT 核心 |
| 1.7 | IQ 解調（虛部） | `Imag = −(2/N) · Σ v(t)·sin(ωt)` | |
| 1.8 | 從 IQ 求相位 | `φ = atan2(Imag, Real)` | |
| 1.9 | 相位誤差（時間延遲造成） | `φ_error = 360° × f × t_delay` | 高頻被線性放大 |
| 1.10 | 雜散電容阻抗 | `Z_stray = 1 / (2π·f·C)` | 纜線約 100 pF/m |
| 1.11 | 雜散電容誤差 | `誤差 ≈ Z_body / Z_stray` | |

### 1.12 AD5940 的阻抗計算（三步驟）

| 步驟 | 公式 | 消掉什麼 | 程式位置 |
|------|------|---------|---------|
| ① 複數除法 | `Z = V/I = [(a·c + b·d) + j(−a·d + b·c)] / (c² + d²)`<br>其中 `a = V_Real`、`b = −V_Imag`、`c = −I_Real`、`d = I_Imag` | ADC、PGA、濾波器、DFT 的增益與相位 | `bia_measurement.c:701-712` |
| ② RTIA 複數乘法 | `Real' = Z.Real×Rtia[0] − Z.Imag×Rtia[1]`<br>`Imag' = Z.Imag×Rtia[0] + Z.Real×Rtia[1]` | TIA 的增益與相位 | `bia_measurement.c:714-720` |
| ③ RCAL 求 Rtia | `Rtia = Z_meas(RCAL) / R_cal` | RCAL 為已知純電阻，理論相位 0° | 開機時執行 |

### 1.13 通用校正式（自製系統可用）

| 名稱 | 公式 | 說明 |
|------|------|------|
| 增益因子校正 | `Z_unknown = R_cal × (Z_measured / Z_cal_measured)` | 複數除法，系統增益與相位一併抵銷 |

### 1.14 相位誤差量化參考

| 頻率 | t_delay = 100 ns 時的相位誤差 | 判讀 |
|------|------------------------------|------|
| 50 kHz | 1.8° | 可校正 |
| 200 kHz | 7.2° | 已大於訊號本身 |
| 250 kHz | 9.0° | 困難 |
| 1 MHz | 36.0° | 不可行（人體真實相位角僅 5~8°） |

### 1.15 雜散電容影響量化參考

| 頻率 | Z_stray（100 pF） | 對 500 Ω 人體的影響 |
|------|-------------------|-------------------|
| 50 kHz | 31.8 kΩ | ~1.6% |
| 200 kHz | 7.96 kΩ | ~6.3% |
| 1 MHz | 1.59 kΩ | **~31%** |

## 第二部分：Cole 模型（頻率 → 體液分區）

### 等效電路

```
              ┌──────── Re ────────┐        Re = 細胞外液電阻
     ●────────┤                    ├────────●   Ri = 細胞內液電阻
              └── Ri ────── Cm ────┘        Cm = 細胞膜電容
```

| # | 名稱 | 公式 | 說明 |
|---|------|------|------|
| 2.1 | Cole 方程式 | `Z(ω) = R∞ + (R₀ − R∞) / (1 + (jωτ)^α)` | 完整模型 |
| 2.2 | 時間常數 | `τ = 1 / (2π·fc)` | |
| 2.3 | 分散係數 α | 真實組織 0.5 ~ 0.8；理想 = 1 | α < 1 會壓低相位角峰值 |
| 2.4 | 特徵頻率 | `fc = 1 / (2π · Cm · (Re + Ri))` | 人體約 30~70 kHz |
| 2.5 | 低頻極限 | `R₀ = Re` | 細胞外液 ECW |
| 2.6 | 高頻極限 | `R∞ = (Re · Ri) / (Re + Ri) = Re ∥ Ri` | 總體水 TBW |
| 2.7 | 反推細胞內液 | `Ri = (R₀ · R∞) / (R₀ − R∞)` | 由 `1/R∞ = 1/Re + 1/Ri` 推得 |
| 2.8 | 細胞內路徑阻抗 | `Z_intra = Ri + 1/(jωCm)` | Ri 與 Cm 串聯 |
| 2.9 | 電流分流比例 | `走細胞內比例 = \| Re / (Re + Z_intra) \|` | |

### 2.10 頻率與電流路徑（示例：Re=700Ω、Ri=900Ω、Cm=3nF）

| 頻率 | 膜阻抗 Xc | 走細胞內的電流比例 | 量到的 \|Z\| | 實際在量什麼 |
|------|----------|------------------|-------------|------------|
| DC | ∞ | 0 % | 700 Ω | 只有細胞外液 |
| 1 kHz | 53 kΩ | 1.3 % | 700 Ω | 幾乎只有細胞外液 |
| **5 kHz** | 10.6 kΩ | 6.5 % | 695 Ω | **細胞外液 ECW** |
| 10 kHz | 5.3 kΩ | 12.6 % | 680 Ω | 過渡區 |
| **50 kHz** | 1.06 kΩ | **36.5 %** | 507 Ω | **混合，產業標準** |
| 100 kHz | 531 Ω | 41.5 % | 434 Ω | 偏向總水分 |
| 200 kHz | 265 Ω | 43.0 % | 405 Ω | 接近總水分 |
| **1 MHz** | 53 Ω | 43.7 % | 394 Ω | **總體水 TBW** |
| ∞ | 0 | 43.75 % | 394 Ω | 理論極限 R∞ |

## 第三部分：幾何層（阻抗 → 體積）

| # | 名稱 | 公式 | 說明 |
|---|------|------|------|
| 3.1 | 歐姆定律（幾何形式） | `R = ρ·L / A` | ρ = 電阻率、L = 長度、A = 截面積 |
| 3.2 | 體積關係 | `V = A · L`　→　`A = V / L` | |
| 3.3 | 代入整理 | `R = ρ·L² / V` | |
| 3.4 | **BIA 基本方程式** | `V = ρ · L² / R` | 導電體積 ∝ 長度² / 電阻 |
| 3.5 | **阻抗指數** | `TBW ∝ H² / R` | L 用身高代理，ρ 假設族群常數 |

> 部分文獻用 `H²/|Z|` 而非 `H²/R`。50 kHz 下差異約 2~4%，但**公式係數不通用**，必須與原始論文一致。

### 3.6 各部位對全身阻抗的貢獻（五圓柱模型）

| 部位 | 佔體重 | 佔全身阻抗 | 意義 |
|------|--------|-----------|------|
| 雙臂 | ~10% | ~45% | 主要訊號來源 |
| 軀幹 | ~50% | **~10%** | ⚠️ 內臟脂肪幾乎測不到 |
| 雙腿 | ~35% | ~45% | 主要訊號來源 |

## 第四部分：體組成迴歸公式

> ⚠️ 以下係數皆為**特定族群**（多為歐美成人）、**特定電極配置**（手↔腳同側、仰臥）、**50 kHz** 推導。
> 使用前確認：① 族群 ② 電極配置 ③ 頻率。正式使用前建議回查原始論文。

### 4.1 主要公式

| # | 項目 | 公式 | 單位 | 來源 |
|---|------|------|------|------|
| 4.1.1 | 總體水 TBW | `TBW = 0.5561×(H²/R) + 0.0955×W + 1.726` | L | Kushner & Schoeller 1986 |
| 4.1.2 | 去脂體重（從 TBW） | `FFM = TBW / 0.732` | kg | Pace & Rathbun 1945 含水率假設 |
| 4.1.3 | **去脂體重（Kyle）** ⭐ | `FFM = −4.104 + 0.518×(H²/R) + 0.231×W + 0.130×Xc + 4.229×sex` | kg | Kyle 2001（歐洲成人，n=343） |
| 4.1.4 | 去脂體重（Sun，男） | `FFM = −10.68 + 0.65×(H²/R) + 0.26×W + 0.02×R` | kg | Sun 2003 NHANES III ⚠️ 建議回查原文 |
| 4.1.5 | 去脂體重（Sun，女） | `FFM = −9.53 + 0.69×(H²/R) + 0.17×W + 0.02×R` | kg | 同上 |
| 4.1.6 | 脂肪重量 | `FM = W − FFM` | kg | 🔴 是「餘數」，不是量出來的 |
| 4.1.7 | **體脂率** | `BF% = (FM / W) × 100` | % | |
| 4.1.8 | **骨骼肌量 SMM** ⭐ | `SMM = 0.401×(H²/R) + 3.825×sex − 0.071×age + 5.102` | kg | Janssen 2000（MRI 驗證，n=388） |
| 4.1.9 | 骨骼肌指數 SMI | `SMI = SMM / H_m²` | kg/m² | 肌少症判定用 |
| 4.1.10 | 軟組織瘦體重 | `SLM = FFM × 0.9425` | kg | 扣除骨礦質約 5.75% |
| 4.1.11 | 骨礦質量 | `BMC ≈ FFM × 0.0575` | kg | 🔴 **推算值，BIA 量不到骨頭** |
| 4.1.12 | 細胞外液（簡化式） | `ECW ≈ 0.180×(H²/R₅kHz) + 0.069×W + 1.2` | L | ⚠️ 各文獻差異大 |
| 4.1.13 | 細胞內液 | `ICW = TBW − ECW` | L | |
| 4.1.14 | 水腫指數 | `Edema = ECW / TBW` | — | 正常 0.360~0.390；>0.400 提示水腫 |
| 4.1.15 | **相位角** ⭐ | `φ = arctan(Xc / R) × 180/π` | 度 | **唯一不需任何假設的直接量測值** |
| 4.1.16 | BIVA 標準化電阻 | `R/H = R / H_m` | Ω/m | 向量分析用，不需體重 |
| 4.1.17 | BIVA 標準化電抗 | `Xc/H = Xc / H_m` | Ω/m | 同上 |
| 4.1.18 | 基礎代謝率 | `BMR = 370 + 21.6 × FFM` | kcal/day | Katch-McArdle |

### 5.1 對照用公式

| # | 項目 | 公式 | 說明 |
|---|------|------|------|
| 5.1.1 | BMI | `BMI = W / H_m²` | |

### 5.2 合理性檢查範圍

| 項目 | 合理範圍（手↔腳全身） | 超出時的判讀 |
|------|---------------------|-------------|
| `R` @50 kHz | 300 ~ 1000 Ω | 電極接觸異常 |
| `Xc` @50 kHz | 20 ~ 150 Ω | 電極接觸異常 |
| `φ` | 3 ~ 12° | 量測無效 |
| `BF%` | 3 ~ 60 % | 計算錯誤或輸入錯誤 |

## 第六部分：🔴 手把式（手↔手）的重要限制

### 6.1 問題

| 配置 | 典型 R 值 | 量到的部位 |
|------|----------|-----------|
| 手↔腳（文獻標準） | 400 ~ 800 Ω | 全身 |
| **手↔手（本專案）** | **300 ~ 500 Ω** | **只有雙臂 + 上軀幹** |

**直接把手↔手的 R 代入 Kyle / Janssen → 系統性錯誤**（通常體脂率被嚴重低估）。

### 6.2 各部位量得到嗎

| 部位 | 佔全身骨骼肌 | 手↔手能量到嗎 |
|------|-------------|--------------|
| 雙臂 | ~15% | ✅ 完整 |
| 軀幹 | ~35% | ⚠️ 只有上半 |
| **雙腿** | **~50%** | ❌ **完全沒有** |

### 6.3 可行做法

| 方案 | 說明 | 成本 | 建議 |
|------|------|------|------|
| ① 建立轉換係數 | 收集 N 人同時量手↔手與手↔腳，迴歸求 `R_全身 ≈ a×R_手手 + b` | 中 | 第二版 |
| ② 自建迴歸 | 收集 N 人的手↔手 R、Xc + InBody/DEXA 結果，直接迴歸 | 高 | 第三版 |
| ③ **只顯示不需公式的指標** | **相位角** + 阻抗趨勢圖 | 低 | ⭐ **第一版** |
