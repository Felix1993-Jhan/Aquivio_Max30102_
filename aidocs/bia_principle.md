# 生物阻抗（BIA）原理筆記

> 建立日期：2026-08-25
> 用途：智慧飲水設備附加功能 —— 手把式體脂／肌肉量測
> 相關文件：[bia_formulas.md](bia_formulas.md)（公式表）、[bia_hardware.md](bia_hardware.md)（硬體設計，待建）

## 0. 一分鐘版本

```
① 人體導電靠「離子在體液中移動」→ 水多電阻小、脂肪電阻大
② 細胞膜是絕緣層 + 兩側導電液 = 天然電容器
③ 低頻電流繞過細胞（只量細胞外液），高頻穿透細胞（量到總水分）
④ 幾何定律 R = ρL/A 推出：體液體積 ∝ H²/R
⑤ 假設「去脂體重含水率固定 73.2%」→ 推出去脂體重
⑥ 脂肪 = 體重 − 去脂體重（是「減出來的餘數」，不是量到的）
```

**最重要的一句話：BIA 量的是「水」，不是「脂肪」。**

  ┌──────┐   ┌────┐   ┌──────┐   ┌──────────┐   ┌────────┐

## 2. 第一層物理：人體為什麼導電

### 導電靠離子，不是電子

金屬導電是自由電子移動；**人體導電是溶液中的離子移動**（Na⁺、K⁺、Cl⁻）。

> **哪裡有水（電解質），哪裡就導電。**

### 各組織電阻率

| 組織 | 含水量 | 電阻率 ρ (Ω·cm) | 導電性 |
|------|--------|----------------|--------|
| 血液 | ~83% | ~150 | 最好 |
| 肌肉（順纖維） | ~75% | ~300 | 很好 |
| 肌肉（垂直纖維） | ~75% | ~800~1500 | 中（**各向異性**） |
| **脂肪組織** | **~10~20%** | **~2000~3000** | **很差** |
| 骨（皮質骨） | ~10% | ~5000~16000 | 幾乎絕緣 |
| 乾燥皮膚 | 低 | MΩ 級 | 絕緣 |

**脂肪的電阻率是肌肉的 5~10 倍**，這是 BIA 的物理起點。

## 3. 第二層幾何：為什麼公式永遠是 H²/R

```
        ρ·L                              ρ·L      ρ·L²
   R = ─────  ,  V = A·L   →    R = ─────────── = ──────
          A                            (V/L)         V

                    L²
        →    V = ρ · ───         →    TBW ∝ H² / R
                    R
```

- `L`（電流路徑長度）→ 用**身高**當代理變數
- `ρ`（電阻率）→ 假設為族群常數
- `V`（導電體積）→ 就是**總體水 TBW**

`H²/R` 稱為 **阻抗指數（Impedance Index）**，是所有 BIA 公式的主要自變數。

### ⚠️ 人體不是均勻圓柱（最大近似誤差來源）

五圓柱模型下，各段對全身阻抗的貢獻：

| 部位 | 佔體重 | 佔全身阻抗 |
|------|--------|-----------|
| 雙臂 | ~10% | **~45%** |
| 軀幹 | ~50% | **~10%** ⚠️ |
| 雙腿 | ~35% | **~45%** |

**軀幹佔一半體重，卻只貢獻 10% 的訊號 → 全身 BIA 幾乎看不到內臟脂肪。**
消費機顯示的「內臟脂肪等級」大多是從腰圍／BMI／年齡回歸的推估值。

## 4. 第三層：為什麼必須用交流電

| 理由 | 說明 |
|------|------|
| **① 電極極化** | 直流在電極-皮膚界面累積電荷 → 反向電動勢 → 讀值持續漂移 |
| **② 電解與傷害** | 直流通過人體會電解體液、造成組織灼傷 |
| **③ 量不到細胞內** | 細胞膜是電容 → 直流完全被阻擋 |

### 細胞膜 = 天然電容器

```
   細胞外液 (ECW)                      細胞內液 (ICW)
   Na⁺ Cl⁻ 濃度高                      K⁺ 濃度高
        │                                    │
        │      ┌────────────────────┐        │
        ├──────┤  磷脂雙層細胞膜     ├────────┤
        │      │  厚度 ~5 nm 絕緣    │        │
        │      └────────────────────┘        │
      導體  ────────  電容 Cm  ──────────  導體

   Cm ≈ 1 µF/cm²（生物物理通用常數）
```

## 5. 核心機制：頻率決定電流走哪條路

### 等效電路（Cole 模型）

```
              ┌──────── Re ─────────┐      Re = 細胞外液電阻
              │      （細胞外路徑）   │      Ri = 細胞內液電阻
     ●────────┤                     ├────────●     Cm = 細胞膜電容
              │                     │
              └── Ri ────── Cm ─────┘
                 （細胞內路徑，必須先穿過細胞膜）
```

`Ri` 和 `Cm` 是**串聯**（電流要進細胞必須先穿膜），整體再與 `Re` 並聯。

### 電容阻抗隨頻率變化

```
              1
   Xc = ────────────
          2π f C

   f ↓（低頻）→ Xc ↑ → 電流走不進細胞
   f ↑（高頻）→ Xc ↓ → 電流可以穿透
```

### 量化示例

假設 `Re = 700 Ω、Ri = 900 Ω、Cm = 3 nF`：

| 頻率 | 膜阻抗 Xc | **走細胞內的電流比例** | 量到的 \|Z\| | 實際在量什麼 |
|------|----------|---------------------|-------------|------------|
| DC | ∞ | **0 %** | 700 Ω | 只有細胞外液 |
| 1 kHz | 53 kΩ | 1.3 % | 700 Ω | 幾乎只有細胞外液 |
| **5 kHz** | 10.6 kΩ | 6.5 % | 695 Ω | **細胞外液 ECW** |
| 10 kHz | 5.3 kΩ | 12.6 % | 680 Ω | 過渡區 |
| **50 kHz** | 1.06 kΩ | **36.5 %** | 507 Ω | **混合，產業標準** |
| 100 kHz | 531 Ω | 41.5 % | 434 Ω | 偏向總水分 |
| 200 kHz | 265 Ω | 43.0 % | 405 Ω | 接近總水分 |
| **1 MHz** | 53 Ω | **43.7 %** | 394 Ω | **總體水 TBW** |
| ∞ | 0 | 43.75 % | 394 Ω | 理論極限 R∞ |

**三個觀察：**
1. 低頻端趨近 `R₀ = 700 Ω` = 細胞外液電阻 `Re`
2. 高頻端趨近 `R∞ = 394 Ω` = `Re ∥ Ri = 700×900/1600`
3. **比例會飽和** —— 超過 200 kHz 後電流分配幾乎不再變化

### 圖示

```
【低頻 < 5 kHz】                    【高頻 > 200 kHz】

  ┌─────── ECW ────────┐            ┌─────── ECW ────────┐
  │  ═══════════════►  │            │  ═════════►        │
  │   ┌──────────┐     │            │   ┌──────────┐     │
  │   │  細胞     │     │            │   │  細胞     │     │
  │   │  ICW  ✗  │     │            │   │  ICW ══►  │     │
  │   └──────────┘     │            │   └──────────┘     │
  │   Cm 阻抗極大       │            │   Cm 阻抗趨近 0     │
  └────────────────────┘            └────────────────────┘
  → 量到 細胞外液 ECW → R₀           → 量到 總體水 TBW → R∞
```

## 6. 相位量測在做什麼

### ⚠️ 常見混淆：相位 ≠ 多頻

**每一個頻率點都同時得到幅值和相位。相位不是靠掃頻才有的。**

```
                    單一頻率              多個頻率
   只量幅值      |Z| = 507Ω            |Z(f)| 曲線
   量幅值+相位   R=487, Xc=−141, φ=16°  Cole 完整模型 → ECW/ICW 分離
```

| 想要什麼 | 需要什麼 |
|---------|---------|
| **體脂率、骨骼肌量、相位角、TBW** | **單頻 50 kHz + 相位** ✅ |
| 細胞內外液分離、水腫指數 | 多頻 + 相位 |

### 相位的價值：把一個數字分解成兩個

```
        Xc（電抗，Ω）
         ▲
    −141 ┤          ／|
         │      ／ φ  |     |Z| = 507 Ω
         │  ／________|
         └────────────┴────────► R（電阻，Ω）
                     487
```

| 分量 | 物理意義 | 生理意義 |
|------|---------|---------|
| **R（電阻）** | 離子在體液中移動的阻力 | **體液總量** |
| **Xc（電抗）** | 細胞膜充放電的阻力 | **細胞膜總面積 ≈ 細胞總量** |
| **φ（相位角）** | 兩者比值 | **細胞品質／完整性** |

### 具體例子：同樣 |Z|，不同身體組成

| | 甲（運動員） | 乙（久坐族） |
|---|---|---|
| \|Z\| | **507 Ω** | **507 Ω** ← 一模一樣 |
| R | 487 Ω | 505 Ω |
| **Xc** | **141 Ω** | **45 Ω** |
| **φ** | **16°** | **5.1°** |
| 判讀 | 細胞量大、細胞膜完整 | 細胞量少、膜品質差 |

**只量幅值 → 兩人無法分辨；量了相位 → 天差地遠。**

## 7. 為什麼業界標準是 50 kHz

### 理由 1：訊號最強的地方

人體組織特徵頻率 **fc ≈ 30~70 kHz**，此處電抗 Xc 達最大 → 相位角最大 → 訊噪比最好。

```
  |Xc|
   │            ▲ 最大值 @ fc ≈ 50 kHz
   │          ╱   ╲
   │        ╱       ╲
   │      ╱           ╲___
   └────────────────────────► log f
     1k      50k      1M
```

### 理由 2：所有經典公式的基準

Kyle、Janssen、Kushner、Sun 全部用 50 kHz 資料建立。換頻率 → 公式係數失效。

### 🔴 理由 3：高頻的雜散電容問題

纜線雜散電容約 100 pF/m，`Zc = 1/(2πfC)`：

| f | Zc | 對 500 Ω 人體的影響 |
|---|-----|-------------------|
| 50 kHz | 31.8 kΩ | ~1.6% |
| 200 kHz | 7.96 kΩ | ~6.3% |
| 1 MHz | 1.59 kΩ | **~31%** 🔴 |

**頻率越高，雜散電容越像短路，把電流從人體旁邊偷走。**
→ 高頻必須做 Driven Shield（主動屏蔽），線要極短。

### 🔴 理由 4：高頻的相位誤差被放大

```
   相位誤差 = 360° × f × t_delay
```

假設系統有 100 ns 固定延遲：

| f | 相位誤差 |
|---|---------|
| 50 kHz | 1.8° |
| 200 kHz | 7.2° |
| 1 MHz | **36.0°** 🔴 |

**人體真實相位角只有 5~8°** —— 1 MHz 的誤差比訊號大 5 倍。
固定延遲可用 RCAL 校正扣掉，但**延遲的漂移**（溫漂、老化）同樣被放大。

### 理由 5：成本與生態系

50 kHz 的 AFE 選擇多、纜線要求低、layout 常規、校正簡單。

## 8. 從電流路徑推導身體組成

```
  低頻量測 R₀  ──────────────►  細胞外液 ECW
  高頻量測 R∞  ──────────────►  總體水 TBW
                                    │
              細胞內液 ICW = TBW − ECW

              1      1     1                  R₀ · R∞
             ─── = ─── + ───    →    Ri = ───────────────
              R∞    Re    Ri                R₀ − R∞
```

再往上推：

```
   TBW ∝ H²/R  →  FFM = TBW / 0.732  →  FM = W − FFM  →  BF%
```

## 9. Cole 模型完整式子

```
                      R₀ − R∞
   Z(ω) = R∞ + ──────────────────
                   1 + (jωτ)^α

   R₀ = 零頻電阻   = Re              → 細胞外液
   R∞ = 無限頻電阻 = Re ∥ Ri         → 總體水
   τ  = 時間常數   = 1 / (2π·fc)
   α  = 分散係數（0.5 ~ 0.8）
```

### α 的意義

理想單一 RC 電路 `α = 1`。真實組織是大量不同大小、形狀的細胞混合，每個時間常數略有不同 → **弭散（dispersion）**。

```
   α = 1     ：完美半圓（理想）
   α = 0.7   ：半圓被壓扁 ← 真實生物組織
   α ↓       ：組織越不均勻
```

**影響：α < 1 會讓相位角峰值比理想模型低。** 這就是為什麼理想模型算出 16°，真實人體只有 5~8°。

### Nyquist 圖

```
   −Xc
    │           ..▪▪▪▪▪▪..
    │        .▪            ▪.        ← 頻率增加方向（右往左）
    │      .▪                ▪.
    │    .▪                    ▪.
    └──●──────────────────────────●───────► R
      R∞                          R₀
    (高頻)                       (低頻)
    394 Ω                        700 Ω
```

## 10. 誤差來源排行（重要）

| 排名 | 誤差來源 | 影響量級 | 能不能改善 |
|------|---------|---------|-----------|
| 🥇 | **水合狀態**（脫水／水腫／飲水／流汗） | **3~8% 體脂** | 靠標準化流程 |
| 🥈 | **迴歸公式族群不匹配** | **2~5% 體脂** | 自建資料庫 |
| 🥉 | **體位**（站／躺、四肢是否貼身） | 2~4% | 靠 UI 引導 |
| 4 | 進食／消化狀態 | 2~3% | 靠流程 |
| 5 | 運動後（血流重分佈） | 2~5% | 靠流程 |
| 6 | 皮膚溫度／環境溫度 | 1~2% | 環境控制 |
| 7 | 電極位置與接觸品質 | 1~2% | 機構設計 |
| 8 | **電子電路精度** | **< 0.5%** | ← AD5940 解決的部分 |

> **電路精度排最後一名。**
> 工程重心應該是：量測流程標準化 > 電極接觸設計 > 迴歸公式校正 > 電路精度。

### ⚠️ 飲水設備場景的特殊問題

**在飲水機旁量體脂，正好是水分變動最大的場景**（排行第 1 名的誤差源）。

因應方式：
- UI 引導「建議在喝水前量測」「固定同一時段」
- **主打趨勢曲線，弱化單次絕對值**
- **主打相位角**（受水分影響遠小於體脂率，且不需任何公式）
- 顯示信心區間，例如「體脂率 22% ± 3%」

## 11. 常見誤解澄清

| 誤解 | 真相 |
|------|------|
| 「BIA 量脂肪」 | ❌ BIA 量**水**，脂肪是用體重減出來的餘數 |
| 「骨量是量到的」 | ❌ 骨頭幾乎不導電，骨量是從 FFM 乘固定比例推的 |
| 「內臟脂肪能測」 | ❌ 軀幹只貢獻 10% 阻抗，全身 BIA 看不到內臟脂肪 |
| 「頻率越多越準」 | ⚠️ 只在 Cole 模型成立且擬合正確時更準，否則只是多雜訊 |
| 「數字跳動 = 機器爛」 | ❌ 多半是身體水分真的在變。**重複性**才是機器好壞指標 |
| 「BIA 可取代 DEXA」 | ❌ DEXA 用 X 光衰減，能分辨骨／脂肪／瘦組織且有空間解析度 |
| 「相位需要掃頻才有」 | ❌ **每個頻率都有相位，單頻也量得到** |
| 「電流會傷身體」 | ❌ 50~500 µA 遠低於感知閾值（約 1 mA），但**心律調節器使用者禁用** |

## 12. 四電極（Kelvin）為什麼是必要的

### 兩電極的問題

```
   Z_measured = Z_電極A + Z_人體 + Z_電極B
                (300~5kΩ)  (500Ω)   (300~5kΩ)
                  ↑ 干擾比訊號還大，且隨握力／乾濕劇烈變動
```

實際後果：
```
   同一人同一機器：
     握緊 → 1800 Ω → 體脂率 15%
     握鬆 → 2500 Ω → 體脂率 25%
```

### 四電極的解法

```
   電流源 ──[F+]── 人體 ──[F−]── 回電流源   ← 注入路徑（接觸阻抗在這，無所謂）
                │      │
              [S+]   [S−]                    ← 感測路徑（幾乎不流電流）
                │      │
              高輸入阻抗差動放大器 → ADC

   感測電極上 I ≈ 0  →  V = I × Z_接觸 ≈ 0  →  接觸阻抗不進入結果
```

### ADI 的命名（F/S）

| 標記 | 全名 | 角色 | ECG 線顏色 |
|------|------|------|-----------|
| **F+** | Force + | 激勵電流注入 | 🔴 紅（E1） |
| **S+** | Sense + | 電壓感測 + | 🟢 綠（E2） |
| **S−** | Sense − | 電壓感測 − | 🔵 藍（E3） |
| **F−** | Force − | 激勵電流流出 | ⚫ 黑（E4） |

**I 電極在外側（遠端／指端），V 電極在內側（近端／掌心），間距 ≥ 3~5 cm。**

理由：
1. 量測區間由 V 電極界定，I 必須在外側
2. 電流剛注入時分佈不均勻，要走一段距離才均勻化

## 14. 手把式（手↔手）配置的限制

本專案採用手把式，等同**手↔手**配置，只量得到上半身。

```
   左手 ○●              ●○ 右手
        ╲                ╱
          ●════════════●     ← 電流只走這裡（雙臂 + 上軀幹）
             上軀幹
          ┌─────────┐
          │  下軀幹  │   ← ❌ 電流不經過
          └────┬────┘
          │  雙腿   │      ← ❌ 完全沒量到（佔全身肌肉 50%）
          └─────────┘
```

| 部位 | 佔全身骨骼肌 | 手↔手能量到嗎 |
|------|-------------|--------------|
| 雙臂 | ~15% | ✅ 完整 |
| 軀幹 | ~35% | ⚠️ 只有上半 |
| **雙腿** | **~50%** | ❌ **完全沒有** |

### 🔴 後果：公開文獻公式不能直接用

Kyle、Janssen 等全部是「手↔腳」推導的：

```
   手↔腳 全身 R  ≈ 400 ~ 800 Ω
   手↔手 上半身 R ≈ 300 ~ 500 Ω    ← 不同的量測對象
```

直接代入會得到系統性錯誤（通常體脂率被嚴重低估）。

### 可行做法

| 做法 | 說明 |
|------|------|
| ① 建立轉換係數 | 收集 N 人同時量手↔手與手↔腳，迴歸求 `R_全身 ≈ a×R_手手 + b` |
| ② 自建迴歸 | 收集 N 人的手↔手 R、Xc + InBody/DEXA 結果，直接迴歸 |
| ③ **只顯示不需公式的指標** | **相位角** + 阻抗趨勢圖 —— 完全不受配置影響 |

**③ 是第一版最誠實、最快、最不會出錯的選擇。**
