# max30102_K2_v007 —— 0.0.0.7 對照核心（只給 App 比較用）

這個資料夾是**改成 0.0.0.8 之前的核心原封複製**（2026-11-02，commit 8bfd7f3 的 `max30102_K2/`），一個字都沒改。

用途：主核心（`../max30102_K2/`）換成 0.0.0.8 的算法之後，App 收到的每一包原始資料同時餵給這一份，
畫面上並排顯示兩邊的 HRV、可信度與谷標點，確認新版沒有比舊版差。

0.0.0.7 與 0.0.0.8 的差別：

| | 0.0.0.7（這裡） | 0.0.0.8（主核心） |
|---|---|---|
| 找谷 / 畫圖的線 | 截尾 → 減 2 秒移動平均 → 13 點移動平均 | 截尾 → 0.7~3.5 Hz 二階 Butterworth 帶通（正反各一次） |
| 找谷範圍 | 5 秒視窗，只丟最右一顆 | 同上，另外只收離最新資料 150 筆以前的谷 |
| 收拍 | 生理閘門 + 近 9 拍 ±40% | 只有生理閘門 |
| 剔除 | clean()：全窗中位數 ± max(2.5×MAD, 50%) | 逐筆對前後各 4 筆的局部中位數分類（±20%） |
| confidence | good / very rough（異常 ≤ 1 次） | good / rough / very rough（乾淨比例） |
